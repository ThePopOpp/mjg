# Acceptance Scripts — Draft 0.6.2

These files are fixtures and expected criteria for manual fictional acceptance conversations. They are not governing policy and are not executed evidence. The supplemental cards under `ACCEPTANCE_RUN_CARDS/` are the preferred ready-to-paste manual test inputs supplied by the recovery kit. Reviewer rubrics must not be pasted as participant prompts.

Record the installed candidate identity, supplied fixture, actual dialogue, TEST CONTROLLER EVENT blocks where used, reviewer identity and criterion-level result. A model must not invent both sides of a conversation and label it an executed test.
