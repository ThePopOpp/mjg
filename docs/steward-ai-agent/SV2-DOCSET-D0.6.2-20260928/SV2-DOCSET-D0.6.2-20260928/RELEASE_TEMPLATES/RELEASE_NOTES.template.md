# Steward release notes — template

Product release: [actual selected version]
Documentation revision and package digest: [exact values]
Base release: [actual verified base]
Status: [draft / staged / authorized / deployed / rolled back]

## Participant change
Explain what is new, for whom, and what remains unchanged. Do not announce an unimplemented feature.

## Exact affected requirements and sources
List changes, owner-direction references, old/new versions and scoped supersession.

## Required engineering and configuration
Code/tool/schema dependencies, offer versions, rights/permission changes and migrations.

## Evidence
Actual test runs, failures/blocked/unknown cases, qualified reviews and residual issues. A list of expected tests is not evidence of success.

## Rollout and rollback
Actual environment, audience, enable/stop conditions, compatibility and deletion/revocation protection.

## Acceptance and delivery
Who approved which scope/digest, actual delivery/receipt, and separate production authorization.
