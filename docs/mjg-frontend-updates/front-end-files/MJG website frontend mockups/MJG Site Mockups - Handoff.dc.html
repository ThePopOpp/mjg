The Stewardship Blueprint website

Seventeen public pages built from MJG_Stewardship_Blueprint_Website_Full_Copy_v1 (Review Edition 1, 21 Oct 2026), styled to the current Next.js frontend in ThePopOpp/mjg. Every page below is a clickable mockup; the shared nav and footer are real components. Dashed amber “Dev note” boxes carry Jeremy’s implementation notes and can be hidden with the showDevNotes tweak on each page.

Design context used

  • app/globals.css tokens → cream #fbfaf7, ink #1c1917, muted #f4f1ea, border #e1dbd0, muted text #6d6660
  • Gold accent #b88a4a (hover #a67c42), dark sections #141211 with light gold #d8bd86 — from site-shell.tsx / join-the-journey.tsx
  • Type: Fraunces (serif headlines, last word in gold) + Geist (UI/body), per SiteHero
  • Chrome: 1160px content box, 2rem gutters, 60px sticky nav, rounded-md buttons (h-12)
  • Logos from public/mjg-logos; photos from public/media

Assumptions

  • Light theme only shown; dark mode follows existing .dark tokens
  • docs/mjg_design_system (Playfair/Figtree) is an older spec — the live React app (Fraunces/Geist) wins
  • Image slots mark where approved assets go (framework art, book cover, guide covers, Filmpool video); none are invented
  • Blueprint page list, week titles, book parts and example scores are illustrative — read from product constants
  • Nav is the doc’s six-item structure with dropdowns; “Take the Free Check-In” is the persistent CTA

Build pattern (Next.js)

  • Wrap each route in SiteShell; replace publicNavItems() with the new six-item nav + children
  • Hero = existing SiteHero (centered or align="left" with media column)
  • Alternate plain / bg-muted/30 border-y / bg-[#141211] sections as shown
  • Join form: first name + email only, separate email/SMS consent → /api/public/join-journey
  • Keep /created-for-more-check-in, /6-week-challenge(/videos), /book-waitlist, /register, /login untouched
