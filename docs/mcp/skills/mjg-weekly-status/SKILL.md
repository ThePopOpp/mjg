# Weekly MJG status

Read-only — nothing is changed or sent.

1. `get_pilot_overview` and `get_pilot_metrics` — participants, waves, funnel.
2. `reports_summary` — Check-Ins (total, last 7 days, average score), Energy Audits, book waitlist.
3. `assessment_results_list` for the last 7 days — only assessments marked "Readable by MCP" appear; say so if one is missing.
4. `groups_list` — published groups, spots confirmed vs capacity, pending requests. `facilitator_applications_list` — anything waiting.
5. `notifications_list` (unread) and `mjg_audit_recent` — anything that failed or needs a person.
6. Write it up: **Headline** (one line) · **Numbers** (this week vs last, as a short table) · **Groups** · **Needs attention** (decisions waiting, failures, people to follow up) · **Suggested next steps** (max 3).

Use plain numbers; don't speculate about causes you can't see in the data. No participant's private answers in the report — counts and trends only.
